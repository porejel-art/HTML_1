# 🌐 Fundamentos de HTML 💻

¡Bienvenido a mi repositorio! ✨

En este proyecto aprenderé los fundamentos de **HTML**, el lenguaje que se utiliza para crear la estructura de las páginas web. 🚀

## 🎯 Objetivo

Conocer las etiquetas principales de HTML y aprender a crear una página web desde cero.

## 📚 ¿Qué es HTML?

HTML significa *HyperText Markup Language* (Lenguaje de Marcado de Hipertexto). Se utiliza para organizar el contenido de una página web, como textos, imágenes, enlaces y listas.

## 🧩 Estructura básica de HTML

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
</head>
<body>
    <h1>¡Hola, mundo! 🌎</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>
```

## 🏷️ Etiquetas principales

* 🔠 `<h1>` a `<h6>`: títulos y subtítulos.
* 📝 `<p>`: crear párrafos.
* 🔗 `<a>`: insertar enlaces.
* 🖼️ `<img>`: agregar imágenes.
* 📋 `<ul>` y `<ol>`: crear listas.
* 📌 `<li>`: agregar elementos a una lista.
* 📦 `<div>`: agrupar elementos.
* 💬 `<br>`: insertar un salto de línea.

## ⚙️ Atributos de HTML

Los atributos proporcionan información adicional a las etiquetas.

**Ejemplo:**

```html
<a href="https://www.google.com">Visitar Google 🔎</a>
<img src="imagen.jpg" alt="Descripción de la imagen">
```

* 🔗 `href`: indica la dirección de un enlace.
* 🖼️ `src`: indica la ubicación de una imagen.
* ♿ `alt`: proporciona una descripción de la imagen.
